**English version:**  
First Python project: integrate-and-fire model with random stimuli.  
Think of a neuron that frequently receives, one by one, random stimuli from another neuron. These stimuli sum together over time (integrate). If the threshold is exceeded, the neuron fires. This illustrates the concept of temporal summation.

**Versione italiana:**  
Primo progetto Python: modello integrate-and-fire con stimoli casuali.  
Si pensi a un neurone che riceve frequentemente nel tempo, uno ad uno, stimoli casuali da un altro neurone. Questi stimoli si sommano fra loro (integrate). Se viene superata la soglia, il neurone spara (fire). Questo è il concetto di sommazione temporale.
